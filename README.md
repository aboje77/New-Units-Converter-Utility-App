# Utility Converter App

The Utility Converter App is a simple web application that allows users to perform different types of conversions quickly and easily. It is built using **HTML**, **CSS**, and **JavaScript**, with each technology handling the structure, design, and functionality of the app.

## Features
- Units Converter (Meter ==> Feet)
- Temperature Converter (Celsius ==> Fahrenheit)
- Color Converter (HEX, RGB)
- Time Converter (Hours ==> Minutes)
- Month Converter (Months ==> Days)

## Technologies Used
- **HTML** – Creates the layout of the application  
- **CSS** – Styles the app and improves appearance  
- **JavaScript** – Handles the conversion logic and interactivity  

## How to Use
1. Download or clone the project.
2. Open the folder.
3. Launch `index.html` in your web browser.
4. Select the converter you need and enter your values.

## Purpose
This project was created to practice basic web development skills and demonstrate how JavaScript can be used to build interactive tools.
